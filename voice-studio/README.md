# استوديو الصوت 🎙️

أداة ويب لتحسين التسجيلات الصوتية للإعلانات والسوشيال ميديا — تعمل بالكامل داخل المتصفح، بدون رفع الملفات لأي سيرفر.

## المزايا
- **إزالة الضجة** (Spectral subtraction) تتعلّم بصمة الضجة من أهدأ مقاطع التسجيل
- **تسكير الصمت** (Noise gate) و**مزيل صفير** ديناميكي (De-esser)
- **تغيير طبقة الصوت** بدون تغيير السرعة (WSOLA)
- **EQ**: قص الواطي، فخامة، تنظيف الكتمة، وضوح، لمعة، قص العالي
- **ضغط** (Compressor) و**صدى** (Reverb)
- **ضبط الارتفاع** حسب معيار ITU-R BS.1770 (‎-14 LUFS للسوشيال ميديا) مع محدد ذروة
- **مقارنة قبل/بعد** بنفس مستوى الارتفاع
- **خامات جاهزة** + **قوالب خاصة** تنحفظ بالمتصفح وتتصدّر/تتستورد كملف JSON
- تصدير **MP3** و**WAV**

## الملفات
| الملف | الوظيفة |
|---|---|
| `index.html` | الواجهة |
| `app.js` | منطق الواجهة وسلسلة المعالجة (Web Audio API) |
| `dsp.js` | خوارزميات المعالجة (بدون مكتبات) |
| `lame.min.js` | ترميز MP3 (lamejs، رخصة LGPL) |
