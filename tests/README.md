# اختبارات حروفي الآلية

تعمل في متصفح حقيقي (Chromium عبر Playwright)، وتُشغَّل تلقائياً قبل كل نشر.

| الاختبار | ماذا يتحقق |
|---|---|
| `test_content.py` | سلامة المحتوى (المقاطع تعيد تكوين الكلمة، لا صور مكررة)، وآلاف الأسئلة المولّدة لكل نشاط: إجابة صحيحة واحدة، بلا خيارات مكررة أو فارغة، وبلا كلمة مكتوبة في تمارين الأصوات للصغار |
| `test_native.py` | يحاكي بيئة تطبيق أندرويد: النطق بمحرّك الجوال، حفظ ومشاركة الشهادات والنسخ الاحتياطي، زر الرجوع، صفحة الخصوصية |
| `test_speech.py` | توقيت الصوت على 3 أنواع أجهزة (عادي، أندرويد بصوت غير معلن، متصفح بلا حدث انتهاء): لا يُنطق السؤال بعد الإجابة، ولا يُقطع المديح |
| `test_writing_check.py` | معايرة تقييم الكتابة باليد واتجاهها على الحروف الـ28 |
| `test_activities.py` | يلعب كل نشاط وكل لعبة في كل الأقسام للعمرين حتى النهاية |

## التشغيل محلياً
```bash
pip install playwright && python -m playwright install chromium
python tests/run_all.py                 # كل الاختبارات
python tests/run_all.py test_speech.py  # اختبار واحد
```
